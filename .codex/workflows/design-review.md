# Design Review Workflow

1. Inspect the existing page, shared components, local theme, and current design references before proposing changes.
2. Compare the implementation with the project context's Mantine v8, Tailwind, typography, icon, accessibility, and responsive rules.
3. Check loading, empty, error, and populated states, plus keyboard use, visible focus, and accessible names for interactive controls.
4. Report concrete mismatches and user impact. Do not invent new design tokens or change shared tokens outside the approved scope.
