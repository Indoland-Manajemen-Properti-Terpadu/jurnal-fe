# Login brand artwork

Created with the built-in imagegen tool for the ProApps Jurnal login showcase. These are conceptual accounting illustrations, not product screenshots or customer data.

Art direction: architectural 3D still life, midnight navy, satin cobalt metal, frosted blue glass and ivory paper, realistic soft lighting. No text, logos, numbers, currency symbols, badges or UI cards. Exported as WebP at quality 85.

- `ledger.webp`: open ruled ledger with a cobalt cover and three precisely aligned frosted glass layers; an understated cyan ribbon traces the composition.
- `reports.webp`: staggered translucent report sheets on a document folio, with sculptural cobalt columns and a silver chart line.
- `reconciliation.webp`: two ivory ruled paper streams aligned through cobalt rectangular frames on a frosted glass base.
