# Bank logos

Drop the official logo of a bank here, named by its bank code from `src/constants/banks.ts`: `014.svg` for BCA, `008.svg` for Mandiri, `022.png` for CIMB Niaga. The Bank Connection page shows it on that bank's card; a bank without a file shows a neutral icon.

Use only files from the bank's own brand kit or press page, and only with the bank's permission: a logo on a product page implies a partnership. When the backend sends a provider with a `logoUrl`, that address wins over a file here.

## Files in this folder

| File | Bank | Source |
|---|---|---|
| `014.png` | BCA | The bank's brand assets page (blue logo), cropped to the mark and resized to 520 px wide |
| `008.png` | Mandiri | The bank's brand folder, "01 Mandiri Master Brand Logo", resized to 520 px wide |
| `022.svg` | CIMB Niaga | Wikimedia Commons (not the bank's own brand kit); replace it with the official file when available |
| `009.svg` | BNI | Wikimedia Commons (not the bank's own brand kit); replace it with the official file when available |

Still without a file (neutral icon shown): BRI `002`, Danamon `011`, Permata `013`, BSI `451`.
