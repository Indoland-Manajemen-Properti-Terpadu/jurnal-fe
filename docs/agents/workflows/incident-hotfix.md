# Incident Hotfix Workflow

1. Establish impact, affected users, scope, and reproducible evidence.
2. Trace the production symptom to a confirmed cause before changing code.
3. Propose the smallest reversible fix and state its risks. Keep unrelated cleanup out of the hotfix.
4. Get approval for any production action, public contract change, or other action that needs authorization.
5. Run the agreed targeted verification and provide a concise recovery and rollback summary.
